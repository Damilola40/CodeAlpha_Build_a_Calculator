# CodeAlpha Calculator

A fully functional calculator built with HTML, CSS and JavaScript.

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, division
- Keyboard support for all operations
- Decimal point handling with duplicate prevention
- Previous and current display for operation history
- CSS Grid layout for clean button structure

## Tech Stack
HTML | CSS | JavaScript
